# yourself.

by Stiluss · [GitHub](https://github.com/Shelbythx) · [Patreon](https://www.patreon.com/cw/St1luss) · [грати](https://shelbythx.github.io/yourself/)

Коротка новела-гра про думки, що приходять одна за одною, про втрату, особисті проблеми і надію.
Лінійна, одноосібна, з камерою зверху. Усе — звичайний статичний сайт без збирання й залежностей.

Мови: українська, English, русский. Звертання на вибір: «ти прийшов» / «ти прийшла» / «ти прийшли».

## Керування

| Дія | Клавіатура | Телефон |
| --- | --- | --- |
| Рух | WASD / стрілки | джойстик (ліва частина екрана) |
| Дія, «далі» в діалогах | E / Enter / Space | кнопка праворуч або тап |
| Пауза | Esc | кнопка «II» |
| Звук увімк./вимк. | M | у меню паузи |

Прогрес зберігається в `localStorage` автоматично.
